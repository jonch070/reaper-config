---------------------------------------------------------------------------------------
 Render LUFS VIP - Changelog (What's new)     
---------------------------------------------------------------------------------------

* v3.0.1 (2025-06-11)
  # fixing windows resize issues
  # changed default fonts for Windows: font 3 set to "Arial", font 4 set to "Impact"
  # additional resize height setting for windows users "windows_titlesize". default to 30 pixels 

* v3.0.0 (2025-06-09)
  + Save parameter used for each track. Allow multiple tracks rendering.
  + Custom LUFS-I or LUFS-SMax parameter per track. (Set for Track # button)
  + option Render Regions Via Master.
  + FX name is now a button to open the FX plugin
  + Ctrl + Mouse Wheel to change font size.
  + display target files one per line if multiple. "maxtargetlines" to specify maximum of lines displayed
  + changes in redesigned UI
  + internal changes, optimizations and bug fixes
 
* v2.2.1 (2024-12-17)
  # fix: broke dry-run with regions and render button in any mode. now it should work.
  + option to overwrite previous rendered files without asking.
  # more tweaks on the output information in the console
  # theming clickable buttons in color

* v2.2.0 (2024-12-15)
  + Faster rendering when using DRY-RUN.
  # fixes for recent versions of REAPER
  # fix crash if user cancels while rendering.
  # fix when not using add render to project and not using old SWS API
  # accept render when difference is in negative tolerance range
  # bigger font for the touched fx and parameter
  # fix ReaLimit in default limiters supported
  # hide "Use old SWS API" for loudness analysis from the UI.
  + display the track name if the plugin is on a track.
  + allow partial match for plugin name search so that if the plugin is renamed it should still find the parameter.
  # minor tweaks

* v2.1.2 (2024-08-17)
  # fix saving settings

* v2.1.1 (2023-09-19)
  + Save preferences in project toggle.
  # some improvements in the way parameter is changed on each render iteration
  + Dry Run button
  + now by default it uses REAPER own loudness calculation when rendering. Use SWS API option for previous method. 

* v2.1.0 (2023-08-10)
  + REAPER 7 support

* v2.0pre6 (2022-07-15)
  + Added Render Targets information. Thanks @RJHollins

* v2.0pre5 (2022-05-03)
  # fix: editable ShortTerm Max target. Thanks @RJHollins
 
* v2.0pre4 (2021-01-29)
  # fix crash when using secondary region for analysis in some cases

* v2.0pre3 (2020-06-26)
  + option to move rendered track above selected track

* v2.0pre2 (2020-04-11)
  # tweak in parameter adjustments for each pass
  # fix: unchecked Add rendered items to new tracks was still leaving the items inserted
  # fix: automation items not saving values correctly

* v2.0pre1 (2020-02-13)
  + Render Region Matrix. Render Multiple files adjusting parameter as needed for each one. 
  + Use secondary focus region. Use smaller region inside each region to optimize parameter for that region instead of the full region.
  + Write automation items for each region with the adjusted parameters as needed.
  + Target to ShortTerm Loudness Max option instead of Integrated Loudness.
  + Add rendered items to new tracks in project.
  + Delete rendered files. Adjusts the parameter, and deletes the rendered file. 
  # results log of all regions rendered at the end of the process

* v1.0 (2019-04-07)
  + support for render settings API (REAPER 5.974 needed) (no more need to change the setting to add into project)
  + GUI for manual configuration of Parameter range.
  + Support multiple parameters configurations per plugin.
  # fix: bad behavior when ripple editing was on. 

* v1.0pre2 (2017-12-15)

* v1.0pre1 (2017-11-21)
